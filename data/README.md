# Synthetic teaching dataset

The app's packaged `births_teaching_sample.csv` contains arbitrary small integer counts for three countries over 2015–2019. It exists only to let the application run offline and to make exact pair calculations easy to inspect. It is not observed or estimated demographic data, and the three-country sum is not a world total. The synthetic values are dedicated to the public domain under CC0-1.0.
